# Zaone V2.1 UI Metrics

Target feel: Windows-like desktop at roughly **125% scaling** on a 1920x1080 display.

## Base metrics
- Xft DPI: 120 (122880 in xfconf units)
- UI font: Noto Sans 10
- Panel height: 44 px at 1080p
- Panel icon size: ~24 px
- Greeter font: 11 pt
- Wallpaper mode: zoomed / scaled, not tiled

## Taskbar direction
- Bottom-centered floating style
- Start/menu on the left of the centered cluster
- Search launcher next to Start
- Pinned app launchers before running apps
- System tray, volume, battery/network and clock on the right
